# Superabasto — Concept & Program Scoping

**Author:** Lizzete Serrano — PMO, Citizens Resources Companies
**Stage:** Concept / pre-development. This repository documents the scoping and program design work I've led so far — there is no software build yet, and this repo does not claim otherwise.

## What Superabasto is

An app that supplies dark kitchens with fruits and vegetables sourced from the Central de Abasto, with four core capabilities:

1. Order connection between dark kitchens and suppliers
2. Real-time product quality analysis
3. Delivery
4. Integration with financing companies for a "buy now, pay later" (BNPL) scheme

## Why this is in my portfolio

Superabasto is one of 7 ventures I own as PMO at Citizens Resources Companies, alongside [Cracks.space](https://github.com/cracks-space/cracks-space-case-study) (live and in deployment) and Umbral (also pre-development). I'm including it here — clearly labeled as pre-development — to show the scope of concurrent ventures I run, not as a technical deliverable.
